Resumen

APP_NAME_PLACEHOLDER te ayuda a guardar recomendaciones. Recopilamos la información necesaria para crear tu biblioteca, generar enlaces con ayuda de IA y permitir que compartas contenido.

Información que recopilamos

  • Datos de cuenta básicos (por ejemplo, correo electrónico).
  • Contenido que guardas en la app: títulos, notas, etiquetas y enlaces.
  • Imágenes o texto que envías para que la IA identifique la recomendación.
  • Información técnica básica (dispositivo, sistema operativo y registros de errores) para mejorar el servicio.

Cómo usamos la información

  • Crear y mantener tu biblioteca de recomendaciones.
  • Generar enlaces a la plataforma correcta mediante IA.
  • Habilitar el envío de enlaces compartidos.
  • Mejorar rendimiento, seguridad y soporte.

IA y terceros

Podemos utilizar proveedores externos para el procesamiento de imágenes o texto (por ejemplo, servicios de IA) con el único fin de identificar recomendaciones y generar enlaces correctos. Estos proveedores están sujetos a obligaciones de confidencialidad y no pueden usar tus datos para otros fines.

Compartir recomendaciones

Cuando compartes una recomendación, creamos un enlace que permite a otras personas verla. Puedes dejar de compartirla eliminándola o revocando el enlace desde la app.

Retención y seguridad

Conservamos la información mientras mantengas tu cuenta activa o mientras sea necesario para prestarte el servicio. Aplicamos medidas de seguridad razonables para proteger tus datos.

Tus derechos

Puedes solicitar acceso, corrección o eliminación de tus datos. Para ejercer estos derechos, contáctanos en contacto@reclib.com.

Contacto

Si tienes dudas sobre esta política, escríbenos a contacto@reclib.com.
